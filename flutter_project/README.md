# تطبيق خدمات الدروة - Flutter

مشروع Flutter رسمي مخصص لتطبيق **خدمات الدروة**، متصل مباشرة بسيرفر PocketBase الخاص بك على أوراكل:
`http://51.170.132.91:8090`

## المميزات المكتملة في تطبيق Flutter:
1. **قائمة الحرفيين ومقدمي الخدمات:** مع الفلترة حسب المهن (كهرباء، سباكة، صباغة...) والبحث الفوري.
2. **الاتصال ومراسلة الواتساب مباشرة:** بضغطة زر واحدة بدون الحاجة لتسجيل الرقم.
3. **دليل الطوارئ والصيدليات والمراكز الصحية:** مع أزرار الاتصال السريع وفتح خرائط Google.
4. **نظام تسجيل حرفي جديد:** لحفظ بيانات أي مهني جديد مباشرة في سيرفر PocketBase.
5. **نظام طلب خدمة ومتابعة الطلبات:** مع حفظ الطلبات وتحديث حالاتها.
6. **دعم اللغة العربية والاتجاه من اليمين لليسار (RTL) تلقائياً.**

## خطوات تشغيل واستخراج ملف الـ APK في حاسوبك:

### 1. تأكد من تثبيت Flutter في جهازك
افتح موجه الأوامر (CMD أو Terminal) واكتب:
```bash
flutter --version
```

### 2. إنشاء مشروع Flutter جديد
في المجلد الذي تريده (مثلاً `C:\projects`):
```bash
flutter create deroua_flutter
cd deroua_flutter
```

### 3. استبدال الملفات
- انسخ محتويات ملف `pubspec.yaml` والصقها في `deroua_flutter/pubspec.yaml`.
- احذف مجلد `lib` القديم في مشروعك، وضع مكانه مجلد `lib` الموجود هنا.

### 4. تحميل المكتبات
داخل مجلد المشروع اكتب:
```bash
flutter pub get
```

### 5. استخراج الـ APK بضغطة زر واحدة 🚀
```bash
flutter build apk --release
```

سيتولد ملف الـ APK النهائي الجاهز للتثبيت على أي هاتف فوراً في المسار:
`build/app/outputs/flutter-apk/app-release.apk`
